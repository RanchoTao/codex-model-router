## Automatic model routing

For every distinct new user task, apply the codex-model-router Skill before substantial execution unless the user explicitly selects a model/reasoning effort or disables routing.

Use the cheapest model and reasoning level likely to complete the task reliably. Do not use Astra merely to classify tasks. Escalate only on evidence of difficulty and preserve useful work when handing off to a stronger agent.
